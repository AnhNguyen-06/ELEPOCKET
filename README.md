# ELEPOCKET
A student-centric financial management platform designed to help students track and optimize their spending habits.

## Key Features
- *Behavioral Quiz:* A logic-based engine that categorizes users into different financial personas: Frugal, Balanced, and Overspending.
- *Personalized Insights:* Provides tailored financial advice and budgeting tips based on user responses.
- *Impact:* Successfully reached *600+ unique visits* and *50+ quiz completions*.

## Tech Stack
- *Languages:* HTML, CSS, JavaScript 
- *Deployment:* [Netlify](https://elepocket.netlify.app/).
